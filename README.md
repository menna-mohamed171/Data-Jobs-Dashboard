# 📊 Data Jobs Dashboard

## 📝 Overview
An interactive **Data Jobs Dashboard** created using **Power BI Desktop**. This project analyzes data job market trends, salary distributions, and required skills based on job posting data. It translates complex employment data into clear visual metrics to help job seekers and analysts understand current market requirements.

---

## 💡 Key Features & Insights
* **Key Metrics (KPIs):** High-level summary cards displaying Total Job Openings, Average Salary, and key job categories.
* **Star Rating Visuals:** Custom Star Rating indicators using DAX Quick Measures to represent ratings and performance categories visually.
* **Role & Salary Breakdown:** Visual comparisons of compensation across various roles (e.g., Data Analyst, Data Scientist, Data Engineer).
* **Interactive Filtering:** Dynamic Slicers allowing users to filter findings by **Experience Level**, **Employment Type**, and **Location**.

---

## 🛠️ Tools & Methodology

| Stage | Tool / Technique | Description |
| :--- | :--- | :--- |
| **Data Source** | `CSV Dataset` | Raw job postings dataset (`job_postings_flat.zip`). |
| **Data Transformation** | **Power Query** | Cleaned raw data, adjusted column types, and verified data consistency. |
| **Calculations & DAX** | **Quick Measures (DAX)** | Generated dynamic metrics including **Star Rating** calculations, average salaries, and counts. |
| **Data Visualization** | **Power BI Desktop** | Built an interactive dashboard using KPI cards, Star Rating visuals, bar charts, and slicers. |
